# DataFrameReporter

## Описание проекта

DataFrameReporter — инструмент для автоматического анализа данных на основе библиотеки pandas.

Класс `DataFrameReporter` позволяет быстро оценить качество датафрейма и получить основные статистические показатели без необходимости каждый раз писать отдельный код для анализа.

### Возможности

- Подсчёт количества строк и столбцов.
- Определение количества и доли дубликатов.
- Вывод сводной статистики с помощью `describe()`.
- Подсчёт количества и доли пропущенных значений.
- Настройка форматирования чисел и процентов.
- Выбор анализа только числовых или всех столбцов.

## Установка и настройка окружения

Для работы необходим установленный Python и менеджер пакетов pip.

**1. Создайте виртуальное окружение:**

```bash
python3 -m venv .venv
```

**2. Активируйте окружение (macOS/Linux):**

```bash
source .venv/bin/activate
```

Для Windows (PowerShell):

```powershell
.venv\Scripts\Activate.ps1
```

**3. Установите зависимости:**

```bash
python -m pip install -r requirements.txt
```

## Запуск проекта

Убедитесь, что файл `payments.csv` находится в директории `data/`.

Запустите программу из корня проекта:

```bash
python main.py
```

Программа создаст два отчёта с разными настройками форматирования.
